# Angular frontend

Angular 21, NgRx 21, Bootstrap 5. TypeScript и шаблоны проверяются в strict-режиме.

Требуется Node.js 22.12+ (рекомендуется 22.21). Из этой папки:

```sh
npm ci
npm start
```

Сервер разработки: `http://127.0.0.1:4200`. `/api` проксируется на backend `http://localhost:8080`. Для прямого запуска backend задайте `APP_ORIGIN=http://127.0.0.1:4200`. В Docker nginx обслуживает интерфейс и API с одной origin; полный запуск описан в README проекта.

```sh
npm test
npm run build
```

Production-файлы: `dist/frontend/browser`. Страницы входа, импорта, списка и карточки загружаются лениво. Список использует NgRx и async pipe, фильтры применяются после 350 мс; новые запросы отменяют устаревшие. Отображается одна адаптивная таблица или набор карточек. Polling импорта не перекрывает HTTP-запросы, подавляет неизменившиеся ответы, завершается при `completed`/`failed` и отменяется при уходе со страницы.

Session и CSRF-token загружаются с `/api/auth/session`, token передаётся в заголовке всех изменяющих запросов, включая вход. Изображения загружаются по защищённому `path` из API. Экспорт скачивает настоящий XLSX всех товаров.

Persistent cache Angular выключен: нативный LMDB на проверяемом macOS окружении аварийно завершал сборку. Dev server использует polling файлов вместо множества системных watchers. Эти настройки не меняют production-файлы.

Unit-тесты проверяют завершение/отмену import polling, отсутствие повторных уведомлений и безопасные сообщения об ошибках. Проверку полного сценария с настоящей БД и Excel выполняют e2e-тесты проекта.
